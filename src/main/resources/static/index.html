OO대학교 컴퓨터공학과를 졸업했고, 웹 서비스 설계와 API 개발에 관심이 많습니다. 팀 프로젝트에서 서버 설계와 배포를 담당했으며, AWS를 활용한 인프라 구축 경험이 있습니다.

단순히 동작하는 코드가 아니라, 유지보수하기 좋고 확장 가능한 구조를 지향합니다.
